# 🏦 ML-система прогнозирования кредитного дефолта (Risk Scoring)

## Описание проекта
End-to-end сервис машинного обучения для предсказания вероятности дефолта клиента по кредиту. Модель обучается на исторических табличных данных, логирует эксперименты и разворачивается в виде REST API микросервиса.

## Стек технологий
* **ML & Data:** Python, Pandas, Scikit-learn, LightGBM, Optuna, SHAP
* **MLOps:** MLflow
* **Backend:** FastAPI, Uvicorn, Docker, Pytest

## Структура репозитория
* `data/` — сырые и обработанные данные (исключены из Git)
* `notebooks/` — Jupyter-ноутбуки с разведочным анализом данных (EDA)
* `src/` — исходный код ML-пайплайна (очистка, генерация признаков, обучение)
* `app/` — микросервис на FastAPI
* `tests/` — автотесты кода
